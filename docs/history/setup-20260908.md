# Setup, adoption and recovery

## Host setup

1. In VS Code, open **Profiles: New Profile**, name it **Advantage360 Native**,
   choose **Copy from Default** (or your current development profile), and create
   the copy. Do not select shared Default contents for settings or shortcuts.
2. In the new profile only, disable Neovim. Alternatively remove its association
   using `code --uninstall-extension asvetliakov.vscode-neovim --profile "Advantage360 Native"`;
   the original profile retains the extension. Keep all other development extensions.
3. Run `python3 bin/manage_host.py preview`. It shows the exact file changes and
   Keyboard Navigation preference. Run `python3 bin/manage_host.py apply` to apply.
4. Reload AeroSpace with `aerospace reload-config`; switch to the native profile
   in VS Code. Do not change the profile of an existing project until ready.
5. Keep ABC selected for programming. Enable **Keyboard Navigation** in macOS
   Keyboard settings (the installer sets the equivalent preference). Full Keyboard
   Access under Accessibility is optional and changes focus handling further.
6. Verify the Spotlight launcher/clipboard actions. The helper verifies Cmd+Space
   is configured, opens Spotlight with it, then checks focus before Cmd+4.
   If macOS blocks System Events, use Spotlight then Cmd+4 manually until the
   calling app has the required macOS Automation/Accessibility permissions.

`python3 bin/manage_host.py export-profile` also writes an importable
`firmware/Advantage360 Native.code-profile`, copying the original profile's
settings, shortcuts, extensions, user tasks and snippets with native bindings
added and Neovim disabled. It stays local because it contains personal settings.
Import it via VS Code's Profiles editor as an alternative to steps 1–2.
The installer never writes the original profile or VS Code's profile registry.

Backups live under `~/.local/state/adv360/backups/<timestamp>/`. The installer
prints the exact restore command. Preview and repeat apply are idempotent.
Restore refuses to overwrite files or the navigation preference changed after
installation. Restore successive installations in reverse order, reloading
AeroSpace and VS Code afterward. Switching back to your original profile is
independent of host-file rollback; profile creation is managed by VS Code.

The environment snapshot retains monitor names from the current workstation.
On another machine, adjust its monitor assignments before first installation;
on the current machine, existing assignments and unrelated bindings are preserved.

## Flash a matched pair

The September 8 NUM revision is `adv360-202609081228-66d6b27-left.uf2` and
`adv360-202609081228-66d6b27-right.uf2`. The immediate previous pair is preserved
under `firmware/rollback-20260906-num/`. The new NUM revision alone does not change
the HID descriptor; if September 6's pointing firmware was already flashed and
paired, another Bluetooth pairing refresh is not required just for this key move.


1. Keep the previous UF2 pair and its manifest. `firmware/rollback/`, when supplied,
   contains a rebuild of the prior repository revision, not a claim that it has
   been tested on this particular keyboard.
2. Build both halves and verify `SHA256SUMS` with `shasum -a 256 -c SHA256SUMS`
   from the firmware directory. Select left/right files with the same prefix.
3. Follow the [Kinesis firmware update procedure](https://kinesis-ergo.com/wp-content/uploads/Advantage360-Professional-Firmware-Update-Instructions-9.5.24-KB360-PRO.pdf).
   Connect each module individually by USB and enter its bootloader with its
   physical reset button. Copy only the matching half's UF2 to its boot drive.
   Let the flashing indication finish. Keep the left module powered while
   updating/reconnecting the right, as directed by Kinesis.
4. Reconnect the halves and verify USB typing before Bluetooth pairing. Never
   interrupt an in-progress flash. The right half has its own recovery button.
5. When upgrading from the original firmware without pointing, the September 6
   workflow update adds a mouse HID report. Forget the old keyboard pairing on each
   affected host and refresh that profile's keyboard-side bond, then pair again
   so the host reloads the descriptor. `SYS+1…5` selects the profile, and the
   SYS `=` + `-` chord clears **that selected host bond**, not all five profiles.
6. Select MAC with `SYS+A`. For Windows/Linux, select the intended BT profile and
   the Ctrl base with `SYS+W`.

Full settings-reset firmware is for documented migration/recovery problems,
not an ordinary layout update. It erases state and requires reinstalling normal
firmware and restoring split pairing. Use the matching vendor reset file and
[reset instructions](https://kinesis-ergo.com/wp-content/uploads/Advantage360-Professional-Settings-Reset-Instructions-11.22.23-KB360-PRO-GBR.pdf)
only when needed. Do not substitute unrelated upstream ZMK reset builds.

## Trial and acceptance

Adopt one part at a time: base/modifiers → NAV/SYM/NUM → EDIT/GLOBAL → POINTER.
Start with relaxed hands and the keyboard's familiar position. Adjust separation,
rotation and tenting gradually so the wrists remain comfortable; avoid compensating
for an awkward reach with a sustained stretch. A layout cannot establish a personal
clinical or ergonomic optimum without actual use.

Before calling the setup complete on hardware, verify:

- Fast prose, `DataFrame`, `HTTPServer`, `snake_case`, and `as sd kl` have no
  unexpected modifiers. Backspace/Delete/Enter/Space repeat on an ordinary hold.
- Both Cmd/Ctrl routes, immediate Shift-click, Shift+arrows, sticky Shift and
  Caps Word work. One-shot Shift affects one following key during fast rolls.
- NUM toggles on/off, Escape exits it, and its digits work with NumLock off.
  Verify U/I/O → 7/8/9, J/K/L → 4/5/6, M/comma/period → 1/2/3, N → 0,
  slash → decimal, backslash → comma and quote → equals. Thumb Space remains Space.
- SYM prints `: _ () [] {} // -> := ** != == <= >= || :: <> __` over USB and BLE.
- NAV moves/selects by character, word, line, page and document. Windows/Linux
  overlays preserve their expected modifiers.
- All 28 EDIT actions work in the native profile; input fields and terminals
  still accept ordinary letters; notebook completion/run controls remain native.
- GLOBAL focuses/moves/resizes windows and moves between both monitors. Workspaces
  1–10 retain their existing arrangement, and every installed-app launcher works.
- POINTER clicks, scrolls and drags. Release a held button after exiting the layer:
  no stuck drag or stray letter should remain. Test modifiers with pointer clicks.
- Both halves reconnect, USB/BLE output selection works, and profiles 0–4 remain
  selectable. Verify physical battery indicators despite disabled host reporting.
- Test a meeting-length idle interval, overnight sleep, wake/reconnect, and first
  keypress behavior. A compile or simulator cannot verify radio or battery behavior.

Compare a representative Python/SQL editing session with the previous setup:
record unintended actions, uncomfortable reaches/holds and mouse interruptions.
Use those observations to decide whether any pointer speed or key position needs
adjustment; do not infer comfort from a keystroke count alone.
