# Advantage360 Pro · macOS engineering workflow

QWERTY firmware for the wireless Kinesis Advantage360 Pro, with immediate
letter keys, dedicated modifiers, and a native VS Code workflow for Python/SQL.
macOS is the default; Windows/Linux retain their Ctrl-oriented base and desktop
consumers. Use **ABC/US while programming** so the symbol legends match output.
Czech remains a host input source for prose; the firmware does not translate it.

## Daily controls

| Control | Action |
|---|---|
| Letters and semicolon | Immediate ordinary keys; no home-row modifiers |
| Inner upper thumbs | Cmd on Mac; Ctrl on Windows/Linux |
| Other upper thumbs | Ctrl on Mac; GUI on Windows/Linux |
| Inner Option keys | Ordinary Option/Alt, on both hands |
| Outer Shift keys | Immediate ordinary Shift, including Shift-click |
| Large thumb keys | Ordinary Backspace, Delete, Enter, Space; hold to repeat |
| Inner top-left hotkey (20) | Caps Word |
| Former Repeat hotkey (21) | One-shot Shift; expires after 1 second |
| Left middle thumb (52) | Hold NAV |
| Right middle thumb (53) | Hold SYM |
| Left bottom thumb (67) | Tap NUM on/off; Escape also exits NUM |
| Right bottom thumb (68) | Hold GLOBAL for windows and applications |
| Inner number-row left key (6) | Hold EDIT for native VS Code commands |
| Inner number-row right key (7) | Tap POINTER on/off; Escape also exits POINTER |
| Bottom-right key (75) | Hold SYS for profiles, output, lights and maintenance |

The duplicate inner Escape/Tab became EDIT/POINTER; ordinary Escape (28) and
Tab (14) remain on the left edge. Repeat remains at position 21 on NUM.
Exit EDIT/POINTER before using SYS. Layers 0–7 retain their indices; EDIT is 8
and POINTER is 9. NUM/POINTER return to the underlying layer when switched off;
if you entered POINTER from NUM, a second Escape leaves NUM as well.

`J K L ;` consistently means **left, down, up, right**:

| Layer | J K L ; | U I O P | Other controls |
|---|---|---|---|
| NAV | Cursor movement | Word-left, page-down, page-up, word-right | H/quote: line edges; Y/backslash: document edges |
| GLOBAL | Window focus | Move window | M/comma/period/slash: resize; H/quote: previous/next monitor |
| EDIT | Editor group focus | Move editor to group | See [all 28 actions](docs/editor.md) |
| POINTER | Move pointer | Scroll left/down/up/right | A/S/D: held left/right/middle mouse button |

On GLOBAL, Y/backslash moves a window between monitors. Shift adds
"take the window there" to workspace/focus signals. N is the host's pin
substitute: fullscreen on macOS, pin on Linux, always-on-top on Windows.

POINTER is an occasional fallback. Tap A for a click, or hold A and use J/K/L/;
for a drag. Release A to drop; there is no drag lock. Unassigned keys are inactive
on EDIT and POINTER so a missed command does not type into another app.
The vendor's default pointer acceleration and scrolling values are retained.

NUM places the number grid directly under U/I/O, J/K/L and M/comma/period:

| Physical keys | NUM output |
|---|---|
| Y · U · I · O · P · backslash | `/` · `7` · `8` · `9` · `*` · `,` |
| H · J · K · L · semicolon · quote | `-` · `4` · `5` · `6` · `+` · `=` |
| N · M · comma · period · slash | `0` · `1` · `2` · `3` · `.` |

The thumb Backspace, Delete, Enter and Space stay available. Digits do not depend
on NumLock; use ABC/US for these punctuation outputs.

SYM keeps `:` under F and `_` under J. `SYM+N` types `//`. Firmware macros emit
short literal operators only; VS Code owns completion, bracket pairs, snippets,
and indentation. Avoid holding unrelated modifiers while invoking text macros.

## macOS desktop and editor

The GLOBAL app bank launches Ghostty, Safari, VS Code, Finder, Spotlight,
Telegram, Obsidian and GitHub Desktop. Native Spotlight supplies clipboard history
through the guarded helper. It requires the standard enabled Cmd+Space Spotlight
shortcut and macOS permission for the calling host to use System Events.
If readiness cannot be established it fails without sending Cmd+4 to another app.

`host/macos/aerospace.preamble.toml` captures the existing ten-workspace environment,
including the PG32UCDM/P34WD-40 display assignments and existing app rules. The
installer merges the F13–F20 bindings into your current config, preserving other
settings. It does not change Hammerspoon. The eight direct workspace keys still
address 1–8; use previous/next workspace or monitor focus for 9–10.

**Advantage360 Native** is a separate VS Code profile copied from the current
profile, with Neovim disabled/excluded only there. F21–F24 combinations belong to
VS Code, never to the desktop manager. Standard shortcuts, notebook controls,
and terminal input remain available. J/K/L/; list navigation is scoped to
`listFocus && !inputFocus`, so input fields keep ordinary letters.

## Firmware, power and recovery

The vendor source is `refil/zmk` at `adv360-z3.5-2`; no experimental firmware
migration is required. Runtime Studio overrides remain disabled.

| Setting | Default |
|---|---|
| Base at power-on | MAC |
| USB | Extended NKRO plus USB boot-protocol support on central |
| Bluetooth | Profiles 0–4; central configured for the host profiles plus split link |
| Idle / deep sleep | 30 seconds / 1 hour |
| White key backlight | Off initially; SYS controls remain available |
| Indicator lighting | Existing vendor effect and settings retained |
| Host BLE battery reports | Disabled; physical battery indicators remain |

BT profiles and OS bases are independent: `SYS+1` through `SYS+5` select slots
0–4; `SYS+A` selects Mac and `SYS+W` selects the Ctrl base. Profile numbers do not
automatically select an OS. Sleep duration and wake reliability require hardware
verification; no battery-saving percentage is assumed.

SYS-only maintenance chords remain bilateral: number-row outer `=` + `-` clears
the current host profile's bond (`BT_CLR`), both outer Shift keys reset, and
positions 20+21 enter the central bootloader. These are physical positions, even
though their base actions changed. Use each half's physical reset button for
recovery. Do not use a settings reset for routine keymap updates.

## Build and validate

Python 3.11+ and Docker or Podman are needed locally.

```sh
make validate                 # structural, protocol, documentation and installer tests
make                          # validate, then build BOTH halves
make left                     # central only, for targeted development
python3 bin/render_keymap.py --write
python3 bin/manage_host.py preview
python3 bin/manage_host.py apply
```

Each build packages a matched pair, effective `.config` files, frozen active
west manifest, exact config source archive, and `SHA256SUMS` under `firmware/`.
Only that invocation's files enter its checksum manifest; old UF2s are not mixed
into the pair. CI also runs real vendor ZMK event regressions for NUM toggling,
immediate Shift, and mouse release across layer exits before building both halves.

To run those event tests locally on Apple Silicon:

```sh
docker build --platform linux/amd64 -t adv360-zmk-tests .
docker run --rm --platform linux/amd64 \
  -v "$PWD:/work:ro" -v "$PWD/firmware/behavior-tests:/results" \
  --entrypoint python3 adv360-zmk-tests \
  /work/bin/test_behaviors.py --output /results
```

For build-specific simulation, mount that build's frozen `-manifest.yml` at
`/app/config/west.yml` in the test container and run `west update` before the
Python test command. Compare the resulting frozen manifest with the firmware
manifest. Cached build and test images can contain different revisions even
when both were created from the same Dockerfile.

GLOBAL/EDIT show host action names with their firmware signals; SYS shows readable
maintenance controls. Muted keys show inherited actions in the stated context:
MAC underneath normal layers, WIN over MAC, and NAVWIN over NAV/WIN/MAC. Other
simultaneously held or toggled layers can change the result. Color separates digits,
operators, modifiers, layer controls, inherited keys and inactive keys.

The text diagrams below retain the compact 76-position matrix view. Both references
are generated from firmware. To regenerate the images, use Python 3.11+ with Pillow:
`python3 bin/render_layer_images.py`; `--font /path/to/font.ttf` overrides the font.
`python3 bin/render_layer_images.py --check` checks sources and artifact fingerprints
without requiring Pillow. The image ZIP contains the overview and ten individual PNGs.
