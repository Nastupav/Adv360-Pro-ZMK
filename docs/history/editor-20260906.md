# Native VS Code action reference

Hold EDIT (inner left number-row key, position 6), then press the listed key.
Actions operate in the **Advantage360 Native** profile. F13–F20 stay with the
desktop manager; F21–F24 combinations stay inside VS Code.

| EDIT key | Signal | Command | Context |
|---|---|---|---|
| `J` | `f21` | `workbench.action.focusLeftGroup` | `any VS Code focus` |
| `K` | `f22` | `workbench.action.focusBelowGroup` | `any VS Code focus` |
| `L` | `f23` | `workbench.action.focusAboveGroup` | `any VS Code focus` |
| `;` | `f24` | `workbench.action.focusRightGroup` | `any VS Code focus` |
| `U` | `shift+f21` | `workbench.action.moveEditorToLeftGroup` | `activeEditor != null` |
| `I` | `shift+f22` | `workbench.action.moveEditorToBelowGroup` | `activeEditor != null` |
| `O` | `shift+f23` | `workbench.action.moveEditorToAboveGroup` | `activeEditor != null` |
| `P` | `shift+f24` | `workbench.action.moveEditorToRightGroup` | `activeEditor != null` |
| `Q` | `ctrl+f21` | `workbench.action.quickOpen` | `any VS Code focus` |
| `W` | `ctrl+f22` | `workbench.action.showCommands` | `any VS Code focus` |
| `E` | `ctrl+f23` | `workbench.action.gotoSymbol` | `activeEditor != null` |
| `R` | `ctrl+f24` | `workbench.action.showAllSymbols` | `any VS Code focus` |
| `A` | `alt+f21` | `workbench.view.explorer` | `any VS Code focus` |
| `S` | `alt+f22` | `workbench.view.search` | `any VS Code focus` |
| `D` | `alt+f23` | `workbench.view.scm` | `any VS Code focus` |
| `F` | `alt+f24` | `workbench.action.terminal.focus` | `any VS Code focus` |
| `Z` | `ctrl+shift+f21` | `editor.action.rename` | `editorTextFocus && !editorReadonly` |
| `X` | `ctrl+shift+f22` | `editor.action.revealDefinition` | `editorTextFocus` |
| `C` | `ctrl+shift+f23` | `editor.action.goToReferences` | `editorTextFocus` |
| `V` | `ctrl+shift+f24` | `editor.action.quickFix` | `editorTextFocus && !editorReadonly` |
| `M` | `alt+shift+f21` | `editor.action.addSelectionToNextFindMatch` | `editorTextFocus` |
| `,` | `alt+shift+f22` | `editor.action.selectHighlights` | `editorTextFocus` |

| `/` | `alt+shift+f24` | `editor.action.smartSelect.shrink` | `editorTextFocus` |
| `T` | `ctrl+alt+f21` | `editor.action.formatDocument` | `editorTextFocus && !editorReadonly` |
| `G` | `ctrl+alt+f22` | `workbench.actions.view.problems` | `any VS Code focus` |
| `H` | `ctrl+alt+f23` | `workbench.action.previousEditor` | `any VS Code focus` |
| `'` | `ctrl+alt+f24` | `workbench.action.nextEditor` | `any VS Code focus` |

J/K/L/; navigate lists only when a list owns focus and no input field is active.
Normal text editing, native shortcuts, notebook keys and terminal input remain
available. Python/Jupyter/Databricks execution stays contextual in those extensions;
firmware does not issue run-query, deployment or terminal command macros.
